Character Works NodeJS Stream Deck Plugin
=========================================

Character Works と直接通信するためのシンプルな Stream Deck プラグインです。  
Companion なしで、Stream Deck から Character Works を操作できます。

## できること

- Motionの起動(StartMotion/StopMotion)
- Textの送信／更新(SetText)
- グリッドセルのアクティベート(ActivateGridcell)

## インストール

1. GitHub の Release から `dev.flowingspdg.characterworks-node.streamDeckPlugin` をダウンロード
2. ダブルクリックするか、Stream Deck アプリからインポート
